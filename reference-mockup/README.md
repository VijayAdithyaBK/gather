# Gather wishlist

Run with Node.js 18 or newer:

```sh
node server.js
```

Then visit http://localhost:4173. Wishlist entries are kept in this browser's local storage. Paste a product URL to try extracting its Open Graph, Twitter card, or JSON-LD product metadata. Many shops limit automated access, so the product form lets you review and edit the title, image URL, price, and category before saving.
